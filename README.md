# agent-group-creator（专家团创建器）

> JiuwenSwarm 平台技能 · 原创

## 功能简介

从自然语言需求创建可被 JiuwenSwarm 加载安装的**专家团（agent_group）包**：一个 Leader + 多个专家成员 + 协作指令 + 可选共享技能。流程沿用「明确需求 → 填充包 → 校验 → 注册」四步，产物是可复用的团队资产而非会话内临时分工。

## 使用场景

- 「组建一个专家团」「做一个多专家协作团队」
- 创建单个专家请用 agent-creator；执行已有专家团的业务任务不需要本技能（由平台路由）。
